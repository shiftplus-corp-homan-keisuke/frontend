## 新しい React プロジェクトの開始：「Far Away」旅行リストアプリ

さあ、このセクションの第二部では、実際のインタラクティブ性を持つ初めてのプロジェクトを構築していきましょう。直接始めていきます。

プロジェクト作成の手順はもうお馴染みですね。Windows をお使いの場合はコマンドプロンプトを、Mac をお使いの場合はターミナルを開いてください。

いつものように、プロジェクトを作成したいフォルダに移動します。私の場合はデスクトップです。

そして、以下のコマンドを実行します：

```bash
npx create-react-app@5 travel-list
```

ここで、バージョン 5 を明示的に指定していることに注意してください。プロジェクト名は「travel-list」としています。

Enter キーを押して、create-react-app に作業を任せましょう。

インストールが進む間に、これから構築するアプリケーションの概要を説明します。

### 「Far Away」アプリの機能紹介

**基本的な機能**：

- **アイテム追加**：次回の旅行に必要なアイテムを追加できます

  - 例：「2 つの搭乗券」を追加すると、リストに表示されます
  - 下部の統計情報も自動的に更新されます

- **アイテム削除**：不要になったアイテムをクリックで削除可能

  - 例：充電器が不要になったら、クリックするだけで削除されます

- **パッキング状態の管理**：アイテムをパッキング済みとしてマーク可能
  - パッキング済みのアイテムは打ち消し線で表示されます
  - 統計情報に「すでにパッキング済み：2 個（50%）」のように反映されます

**高度な機能**：

- **3 つの並び替えオプション**

  - 入力順（Input order）
  - 説明順（Description）
  - パッキング状態順（Packed status）

- **一括クリア機能**
  - 旅行から帰ってきて次の旅行の準備をする際に便利
  - 確認ダイアログが表示され、安全にリストを空にできます

このアプリケーションは、レトロで温かみのあるデザインが特徴的で、旅行の雰囲気にとてもよく合っています。

### コンポーネント設計の考え方

コードを書き始める前に、このデザインをどのようにコンポーネントに分割するかを考えましょう。

**主要コンポーネントの識別**：

1. **Logo コンポーネント**

   - 大きな黄色い部分
   - アプリケーションのタイトルとアイコンを表示

2. **Form コンポーネント**

   - 新しいアイテムを追加するためのフォーム
   - セレクトボックス（数量選択）
   - テキスト入力フィールド（アイテム名）
   - 追加ボタン

3. **PackingList コンポーネント**

   - アイテムのリスト全体を管理
   - 個々のアイテムコンポーネントを含む

4. **Item コンポーネント**

   - 各アイテムの表示と操作を担当
   - チェックボックス、削除ボタンなどを含む

5. **Stats コンポーネント**
   - 下部の統計情報を表示
   - パッキング進捗の計算と表示

この分割により、各コンポーネントが明確な責任を持ち、再利用可能で保守しやすいコードベースを構築できます。

## アイテムリストのレンダリング

React アプリケーション開発において、リストのレンダリングは最も一般的なタスクの一つです。このアプリケーションでも例外ではありません。パッキングアイテムのリストをレンダリングしていきましょう。

### 初期データの準備

まず、CSS ファイルに含まれている初期アイテムの配列を取得します。index.js ファイルを閉じて、このデータを App.js ファイルの最上部に貼り付けます。

```javascript
const initialItems = [
  { id: 1, description: "Passports", quantity: 2, packed: false },
  { id: 2, description: "Socks", quantity: 12, packed: false },
  { id: 3, description: "Charger", quantity: 1, packed: false },
];
```

**データ構造の理解**：
各オブジェクトには以下のプロパティがあります：

- **id**: 一意の識別子
- **description**: アイテムの説明
- **quantity**: 数量
- **packed**: パッキング済みかどうかのブール値

`packed`プロパティに基づいて、アイテムの表示方法を変更します。パッキング済みのアイテムは打ち消し線で表示されます。

### PackingList コンポーネントでのリスト表示

```javascript
function PackingList() {
  return (
    <div>
      <ul className="list">
        {initialItems.map((item) => (
          <Item item={item} key={item.id} />
        ))}
      </ul>
    </div>
  );
}
```

**重要なポイント**：

- **セマンティック HTML**: `<ul>`（順序なしリスト）を使用してリストの意味を明確にします
- **map メソッド**: 配列の各要素を JSX にマッピングします
- **key プロパティ**: 各要素にユニークなキーを提供（`item.id`を使用）

### Item コンポーネントの作成

各アイテムを表示するための専用コンポーネントを作成します：

```javascript
function Item({ item }) {
  return (
    <li>
      <span style={item.packed ? { textDecoration: "line-through" } : {}}>
        {item.quantity} {item.description}
      </span>
      <button>❌</button>
    </li>
  );
}
```

**コンポーネント設計の特徴**：

1. **プロパティの分割代入**: `{ item }`でプロパティを直接抽出
2. **条件付きスタイリング**: 三項演算子を使用してパッキング済みアイテムに打ち消し線を適用
3. **セマンティック HTML**: `<li>`要素を使用（`<ul>`の直接の子要素として適切）

### スタイリングの修正

正しい CSS クラスを適用するために、HTML 構造を少し調整する必要があります：

```javascript
function PackingList() {
  return (
    <div>
      <div className="list">
        <ul>
          {initialItems.map((item) => (
            <Item item={item} key={item.id} />
          ))}
        </ul>
      </div>
    </div>
  );
}
```

この構造により、後でフィルタリング機能を追加する際のためのスペースも確保できます。

### 動作確認

ブラウザでアプリケーションを確認すると、以下が表示されることを確認できます：

- "Passports" と "Socks" が通常の表示
- 各アイテムに削除ボタン（❌）が表示
- レイアウトが想定通りに機能

パッキング状態をテストするために、一時的に配列内のアイテムの`packed`プロパティを true に変更してみると、そのアイテムに打ち消し線が適用されることが確認できます。

このリストレンダリングのパターンは、React 開発において非常によく使用される基本的なテクニックです。map メソッドと適切な key 属性の使用方法をしっかりと理解しておくことが重要です。

## フォームの構築と submit の処理

Web アプリケーションにおいて、フォームを通じたユーザーとの対話は最も重要な要素の一つです。フォームは Web アプリケーションの基本的な構成要素です。React でフォームを扱う方法を学んでいきましょう。

### 基本的な HTML フォーム要素の作成

React でフォームを構築する際は、通常の HTML フォーム要素を使用します。

```javascript
function Form() {
  return (
    <form className="add-form">
      <h3>What do you need for your trip? 😍</h3>

      <select>
        {Array.from({ length: 20 }, (_, i) => i + 1).map((num) => (
          <option value={num} key={num}>
            {num}
          </option>
        ))}
      </select>

      <input type="text" placeholder="Item..." />

      <button>Add</button>
    </form>
  );
}
```

**フォーム要素の解説**：

1. **セレクトボックス（数量選択）**：

   - `Array.from({ length: 20 }, (_, i) => i + 1)` は 1 から 20 までの配列を生成
   - この技術は React でよく使用される便利なトリック
   - 手動で 20 個のオプションを書く必要がありません

2. **テキスト入力フィールド**：

   - type="text"と placeholder を設定
   - ユーザーがアイテム名を入力します

3. **送信ボタン**：
   - フォームの送信をトリガーします

### イベントハンドリングの実装

フォーム送信を処理するためのイベントハンドラーを作成します：

```javascript
function Form() {
  function handleSubmit(e) {
    e.preventDefault(); // ページリロードを防ぐ
    console.log("Form submitted");
  }

  return (
    <form className="add-form" onSubmit={handleSubmit}>
      {/* フォーム要素 */}
    </form>
  );
}
```

**重要なポイント**：

1. **preventDefault()の必要性**：

   - HTML の標準動作では、フォーム送信時にページがリロードされます
   - Single Page Application（SPA）では、ページリロードなしでデータを処理したいため
   - `e.preventDefault()`でこの標準動作を無効にします

2. **送信イベントのトリガー**：

   - ボタンクリック時
   - 入力フィールドで Enter キー押下時
   - これらは標準的な HTML 動作です

3. **イベント vs onClick**：
   - `onSubmit`はフォーム全体に適用し、HTML フォームの力を活用
   - `onClick`をボタンに適用すると、Enter キーでの送信ができなくなります

### フォームデータの取得方法

現時点では、フォームが送信されてもデータを取得していません。次のセクションでは、「制御されたコンポーネント」という重要な概念を学び、フォームデータを適切に管理する方法を習得します。

```javascript
function handleSubmit(e) {
  e.preventDefault();

  // イベントオブジェクトから情報を取得する方法（推奨されない）
  console.log(e); // SyntheticBaseEvent オブジェクト
  console.log(e.target); // フォーム要素そのもの

  // より良い方法は制御されたコンポーネントを使用すること
}
```

このイベントオブジェクトからデータを取得することも可能ですが、React では「制御されたコンポーネント」という、より優れた方法を使用します。

### HTML フォームの標準機能の活用

React では、HTML フォームの標準的な機能を最大限に活用することが重要です：

- **アクセシビリティ**: スクリーンリーダーなどの支援技術に対応
- **キーボードナビゲーション**: Tab キーでの移動、Enter キーでの送信
- **ブラウザの標準検証**: required 属性などの活用

次のセッションでは、React でフォームデータを管理するための「制御されたコンポーネント」について詳しく学習し、このフォームを完全に機能させる方法を習得します。
