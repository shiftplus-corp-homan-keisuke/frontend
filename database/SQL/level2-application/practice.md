# Level 2: Application - SQL中級練習問題

## 概要

このファイルには、データベーススペシャリスト試験の中級レベルに対応した練習問題が含まれています。基礎レベルで学習した内容を前提として、より高度なSQL技術を段階的に習得できるよう設計されています。

## 使用するテーブル構造

以下のテーブル構造を前提として問題を作成しています：

```sql
-- 従業員テーブル
CREATE TABLE employees (
    employee_id INT PRIMARY KEY,
    first_name VARCHAR(50),
    last_name VARCHAR(50),
    email VARCHAR(100),
    phone_number VARCHAR(20),
    hire_date DATE,
    job_id VARCHAR(10),
    salary DECIMAL(8,2),
    commission_pct DECIMAL(2,2),
    manager_id INT,
    department_id INT
);

-- 部署テーブル
CREATE TABLE departments (
    department_id INT PRIMARY KEY,
    department_name VARCHAR(50),
    manager_id INT,
    location_id INT
);

-- 所在地テーブル
CREATE TABLE locations (
    location_id INT PRIMARY KEY,
    street_address VARCHAR(100),
    postal_code VARCHAR(12),
    city VARCHAR(50),
    state_province VARCHAR(50),
    country_id CHAR(2)
);

-- 職種テーブル
CREATE TABLE jobs (
    job_id VARCHAR(10) PRIMARY KEY,
    job_title VARCHAR(50),
    min_salary DECIMAL(8,2),
    max_salary DECIMAL(8,2)
);

-- 国テーブル
CREATE TABLE countries (
    country_id CHAR(2) PRIMARY KEY,
    country_name VARCHAR(50),
    region_id INT
);

-- 職歴テーブル
CREATE TABLE job_history (
    employee_id INT,
    start_date DATE,
    end_date DATE,
    job_id VARCHAR(10),
    department_id INT,
    PRIMARY KEY (employee_id, start_date)
);
```

## セクション1: 外部結合（OUTER JOIN）

### 問題1-1: 基本的な左外部結合
全従業員の情報と所属部署名を表示してください。部署未配属の従業員も含めて表示してください。

### 問題1-2: 右外部結合の活用
全部署の情報と部署に所属する従業員数を表示してください。従業員がいない部署は0として表示してください。

### 問題1-3: 複数テーブルの外部結合
全従業員の情報（従業員ID、氏名、部署名、所在地の都市名）を表示してください。部署未配属や所在地不明の従業員も含めて表示してください。

### 問題1-4: 外部結合での条件指定
東京（Tokyo）以外の都市にある部署の従業員情報を表示してください。部署未配属の従業員も含めて表示してください。

### 問題1-5: 完全外部結合（対応DBMS限定）
従業員テーブルと部署テーブルの完全な対応関係を表示してください。従業員がいない部署と部署未配属の従業員の両方を含めてください。

## セクション2: サブクエリと相関サブクエリ

### 問題2-1: 基本的なサブクエリ
全従業員の平均給与より高い給与を受け取っている従業員の情報を表示してください。

### 問題2-2: IN句でのサブクエリ
東京（Tokyo）にある部署に所属する従業員の情報を表示してください。

### 問題2-3: EXISTS句でのサブクエリ
従業員が所属している部署のみを表示してください。

### 問題2-4: 相関サブクエリ（基本）
各部署で最も給与が高い従業員の情報を表示してください。

### 問題2-5: 相関サブクエリ（応用）
自分の部署の平均給与より高い給与を受け取っている従業員の情報を表示してください。

### 問題2-6: NOT EXISTS句の活用
従業員が一人もいない部署の情報を表示してください。

### 問題2-7: 複数列サブクエリ
各部署で最も給与が高い従業員と同じ給与・職種の組み合わせを持つ全従業員を表示してください。

### 問題2-8: サブクエリでの集約関数
各部署の従業員数が全社平均の従業員数より多い部署の情報を表示してください。

## セクション3: CASE文とCOALESCE関数

### 問題3-1: 基本的なCASE文
従業員の給与を以下の基準で分類して表示してください：
- 10000以上：「高給」
- 5000以上10000未満：「中給」
- 5000未満：「低給」

### 問題3-2: CASE文での複数条件
従業員の勤続年数（hire_dateから計算）を以下の基準で分類してください：
- 10年以上：「ベテラン」
- 5年以上10年未満：「中堅」
- 5年未満：「新人」

### 問題3-3: 集約関数でのCASE文
各部署について、以下の情報を表示してください：
- 部署名
- 総従業員数
- 高給（8000以上）の従業員数
- 中給（5000以上8000未満）の従業員数
- 低給（5000未満）の従業員数

### 問題3-4: CASE文での条件別集計
各部署の給与統計を以下の形式で表示してください：
- 部署名
- 平均給与
- 最高給与
- 最低給与
- 給与レンジ（「最低給与 - 最高給与」の形式）

### 問題3-5: COALESCE関数の基本
従業員の連絡先情報を以下の優先順位で表示してください：
1. 電話番号
2. メールアドレス
3. 「連絡先なし」

### 問題3-6: COALESCE関数での計算
従業員の総収入（給与 + コミッション）を計算してください。コミッション率がNULLの場合は0として計算してください。

### 問題3-7: CASE文とCOALESCEの組み合わせ
従業員の給与情報を以下の形式で表示してください：
- 基本給与
- コミッション（NULLの場合は「なし」）
- 総収入
- 収入レベル（高・中・低）

## セクション8: 応用問題

### 問題8-1: 複合的な分析クエリ
各部署について、以下の情報を1つのクエリで取得してください：
- 部署名
- 所在地（都市名）
- 従業員数
- 平均給与
- 最高給与の従業員名
- 最低給与の従業員名

### 問題8-2: 階層データの処理
従業員の管理階層を表示してください（従業員 → 直属の上司 → その上司...）。

### 問題8-3: 時系列分析
各年の新入社員数の推移を表示してください。

### 問題8-4: 複雑な条件での抽出
以下の条件を満たす従業員を抽出してください：
- 自分の部署で給与上位3位以内
- かつ、全社で給与上位50%以内
- かつ、勤続年数5年以上

### 問題8-5: データ品質チェック
以下のデータ品質問題を検出するクエリを作成してください：
- 部署に所属しているが、その部署が存在しない従業員
- 上司が存在しない管理者ID
- 給与が職種の給与範囲外の従業員

### 問題8-6: パフォーマンス分析
部署別の給与効率（総給与に対する売上貢献度）を分析するクエリを作成してください。

### 問題8-7: 動的レポート
月別・部署別の人員変動レポートを作成してください。

### 問題8-8: 複雑な集計
各従業員について、以下の情報を表示してください：
- 基本情報（ID、氏名、部署名）
- 給与情報（給与、部署内順位、全社順位）
- 比較情報（部署平均との差、全社平均との差）
- 統計情報（部署内パーセンタイル、全社パーセンタイル）

2. 各問題を自分で考えてからSQL文を作成
3. 実際のデータベースで実行して結果を確認
4. 解答と比較して理解を深める
5. 間違えた問題は理論に戻って復習
