## セクション1: 基本SELECT文

### 問題1-1: 全データの取得
従業員テーブル（employees）から全ての列と全ての行を取得してください。

### 問題1-2: 特定列の取得
従業員テーブルから従業員ID、名前（first_name）、姓（last_name）のみを取得してください。

### 問題1-3: WHERE句による条件指定
従業員テーブルから部署ID（department_id）が10の従業員の情報を全て取得してください。

### 問題1-4: 複数条件の指定
従業員テーブルから部署ID が10で、かつ給与（salary）が500000以上の従業員を取得してください。

### 問題1-5: 範囲指定
従業員テーブルから給与が500000以上800000以下の従業員の名前、姓、給与を取得してください。

### 問題1-6: パターンマッチング
従業員テーブルから名前（first_name）が「D」で始まる従業員の情報を取得してください。

### 問題1-7: NULL値の検索
従業員テーブルからcommission_pctがNULLの従業員の名前、姓、commission_pctを取得してください。

### 問題1-8: ORDER BY句による並び替え
従業員テーブルから全ての従業員を給与の降順で取得してください。

### 問題1-9: 複数列での並び替え
従業員テーブルから全ての従業員を部署ID の昇順、その中で給与の降順で取得してください。

### 問題1-10: LIMIT句による件数制限

## 学習のポイント

### 1. SQL文の記述順序
- SELECT句 → FROM句 → WHERE句 → GROUP BY句 → HAVING句 → ORDER BY句 → LIMIT句の順序を意識する

### 2. 集約関数の使用時の注意点
- GROUP BY句なしで集約関数を使用する場合は、SELECT句に通常の列を含められない
- NULL値は集約関数の計算から除外される（COUNT(*)を除く）

### 3. JOINの理解
- 結合条件を正しく指定する
- テーブルエイリアスを使用して可読性を向上させる

### 4. データ操作時の注意点
- WHERE句を忘れると予期しない範囲のデータが影響を受ける
- 外部キー制約を意識する

### 5. 実行計画の考慮
- インデックスが設定されている列での条件指定を心がける
- 不要な結合や集約を避ける
