# 1on1学習 実習ガイド

## 基本方針：「理論20% : 実習80%」

### 従来の問題点
```
❌ 講師が長時間説明 → 学習者が受動的
❌ コード例を見るだけ → 実際に書けない
❌ 練習問題の時間不足 → 理解が浅い
```

### 改善後のアプローチ
```
✅ 最小限の説明 → すぐに実習開始
✅ ペアプログラミング形式 → 能動的学習
✅ 十分な練習時間 → 確実な理解
```

## 実習の進め方

### Phase 1: 導入（5-10分）
**講師の役割**:
- 今日学ぶことの概要を簡潔に説明（3分以内）
- 「なぜ重要なのか」を具体例で示す
- 学習者の前提知識を確認

**学習者の活動**:
- 質問があれば積極的に発言
- 今日の目標を自分の言葉で確認

### Phase 2: 基本実習（30-40分）
**講師の役割**:
- 最初の1-2例を一緒にコーディング
- 学習者がコードを書く際のサポート
- エラーが出た時の解決支援

**学習者の活動**:
- 実際にコードを書いて動作確認
- 分からない点はすぐに質問
- 自分なりの理解を言葉で説明

### Phase 3: 応用実習（30-40分）
**講師の役割**:
- より複雑な例題を提示
- ヒントを出しながら学習者の思考をサポート
- 複数の解決方法を一緒に検討

**学習者の活動**:
- 自分で考えながらコーディング
- 試行錯誤を恐れずに挑戦
- 講師と議論しながら最適解を見つける

### Phase 4: 振り返り（5-10分）
**講師の役割**:
- 学習内容の要点を整理
- 次回への接続を説明
- 学習者の理解度を確認

**学習者の活動**:
- 今日学んだことを自分の言葉でまとめ
- 疑問点や不安な点を共有
- 次回までの予習内容を確認

## 実習のコツ

### 講師向け
1. **説明は最小限に**: 長い説明より、実際に動かして見せる
2. **エラーを恐れない**: エラーも学習の一部として活用
3. **学習者のペースに合わせる**: 理解度を確認しながら進行
4. **質問を促す**: 「ここまでで質問はありますか？」を頻繁に

### 学習者向け
1. **積極的に手を動かす**: 見るだけでなく、必ず自分で書く
2. **分からないことは即質問**: 遠慮せずにその場で解決
3. **自分の理解を言葉にする**: 「つまり〜ということですね」
4. **エラーを楽しむ**: エラーから学ぶことが多い

## 実習環境の準備

### 必要なツール
```bash
# 基本環境
- Node.js (最新LTS版)
- TypeScript
- VS Code (推奨エディタ)

# Zod学習用
npm install zod
npm install -D typescript @types/node

# 実習用プロジェクト作成
mkdir zod-practice
cd zod-practice
npm init -y
npm install zod typescript @types/node
npx tsc --init
```

### VS Code設定
```json
// .vscode/settings.json
{
  "typescript.preferences.includePackageJsonAutoImports": "on",
  "editor.codeActionsOnSave": {
    "source.fixAll": true
  },
  "editor.formatOnSave": true
}
```

## 成功指標

### セッション終了時の確認項目
- [ ] 学習者が自力でコードを書けるようになった
- [ ] エラーが出ても自分で解決できるようになった
- [ ] 概念を自分の言葉で説明できるようになった
- [ ] 次のセッションへの準備ができている

### 学習効果の測定
1. **理解度テスト**: 簡単な問題を即座に解けるか
2. **応用力テスト**: 少し変更した問題に対応できるか
3. **説明力テスト**: 他の人に教えられるレベルか
4. **実践力テスト**: 実際のプロジェクトで使えるか
