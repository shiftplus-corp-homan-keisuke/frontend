# 曳光弾 (Tracer Bullets) in Angular

## 概念: 暗闇を照らす
『達人プログラマー』の曳光弾（トレーサー・ブレット）とは、システム全体のアーキテクチャが機能するかどうかを早期に検証するために、**全レイヤー（UI〜DB）を貫通する、薄いが動くコード**を書く手法です。

### プロトタイプとの違い
- **プロトタイプ**: 使い捨て。実験が終わったら捨てる（ハリボテ）。
- **曳光弾**: 本番コードの一部。最初は機能が空っぽだが、徐々に肉付けされて最終製品になる（コンクリートの骨組み）。

Angular開発において、曳光弾は「空のコンポーネント、モックサービス、ルーティング」を一気に繋げ、**画面遷移とデータの流れだけを先に確立する**アプローチになります。

## 学習用ファイル

1. `mock-auth.service.ts`
   - 本物の認証基盤がまだなくても、認証済み/未認証の状態を切り替えてテストできるようにする「弾丸（モック）」。
2. `app.routes.ts`
   - まだ画面の中身が空でも、URLと画面遷移の構造（スケルトン）を先に作る。
3. `feature-shell.component.ts`
   - 詳細は未実装だが、レイアウトとルーティングの受け皿として機能するシェル。
