# セクション概要

ここでは、基本的なReactのトピックを引き続き探求し、最終的にコンポーネントに何らかの動作をさせます。
つまり、コンポーネントをインタラクティブにします。
そのためには、Reactでのイベントの処理方法と、非常に重要な概念である状態（state）を使用してユーザーインターフェースを更新する方法を学び始めます。
また、次のプロジェクトの構築も開始します。ここでは、状態と、制御された要素を使用してReactの流儀でフォームを構築することに焦点を当てます。
セクションの終わりには、PropsとStateについて、理論と実践の両方で学んだすべてを、非常に優れた小さなフラッシュカードアプリケーションを構築することによって要約します。
したがって、繰り返しますが、これはあなたにとって非常に不可欠で基礎的なセクションですので、すぐに進みましょう。
