## 🔧 指導テクニック

### よくある質問と推奨回答

#### インターフェース関連

**Q**: 「インターフェースと型エイリアスの違いがわからない」
**A**: 
```typescript
// インターフェース: オブジェクトの構造定義、継承可能
interface User {
  id: number;
  name: string;
}

interface Student extends User { // 継承可能
  grade: number;
}

// 型エイリアス: 型の別名、ユニオン型など
type Status = "active" | "inactive"; // ユニオン型
type UserId = number; // プリミティブ型の別名
```

**Q**: 「どのプロパティをreadonlyにすべきですか？」
**A**: 
- ID、作成日時など、一度設定したら変更されないもの
- 外部システムから取得した変更権限のないデータ
- 計算結果など、直接変更されるべきでないもの

#### 継承関連

**Q**: 「複数のインターフェースを継承する際の注意点は？」
**A**: 
- 同名プロパティがある場合は型が互換性を持つ必要がある
- 継承の順序は型チェックに影響しない
- 意味的に関連するインターフェースのみを継承する

#### 実装関連

**Q**: 「型エラーが解決できません」
**A**: 
1. エラーメッセージを正確に読む
2. 期待される型と実際の型を確認
3. 型注釈を明示的に追加して確認
4. TypeScript Playgroundで簡単な例で試す
