# Step 02 学習ガイド：基本型システムと型注釈

> 💡 **重要**: Step02 は**Core（基礎編）**と**Advanced（発展編）**に分割されています
>
> 初学者は必ず**Step02-Core**から始めて、完全に理解してから**Step02-Advanced**に進んでください

## 📋 学習の進め方

### Phase 1: 基礎固め（必須）

**📖 [Step02-Core: 基本型システム入門](./Step02-Core_基本型システム入門.md)**

- **学習時間**: 2 時間
- **内容**: プリミティブ型、配列、オブジェクト、関数の基本
- **目標**: TypeScript の基本的な型注釈を書けるようになる

### Phase 2: 発展学習（推奨）

**📖 [Step02-Advanced: 型システム深掘り](./Step02-Advanced_型システム深掘り.md)**

- **学習時間**: 2-4 時間
- **内容**: 高度な型推論、タプル型、読み取り専用配列、高階関数
- **目標**: 実践的な型システムパターンを身につける

## 🎯 学習目標の確認

### Step02-Core 完了後にできること

- [ ] string, number, boolean 型を正しく使える
- [ ] 配列型（string[], number[]）を定義できる
- [ ] オブジェクトの基本的な型注釈を書ける
- [ ] 関数の引数と戻り値に型を付けられる
- [ ] 基本的な型エラーを読んで修正できる

### Step02-Advanced 完了後にできること

- [ ] 型推論の高度なパターンを理解できる
- [ ] タプル型を実践的に活用できる
- [ ] 読み取り専用配列で安全なコード設計ができる
- [ ] 高階関数の型注釈を正しく書ける
- [ ] 複雑なオブジェクト型を設計できる

## ⚠️ 学習上の注意点

### 1. 段階的な学習を心がける

```
❌ 間違い: いきなりAdvancedから始める
✅ 正解: Core → Advanced の順序で学習
```

### 2. 実践重視で学習する

```
❌ 間違い: 理論だけを読んで満足する
✅ 正解: 必ずコードを書いて動作確認する
```

### 3. エラーを恐れない

```
❌ 間違い: エラーが出たら諦める
✅ 正解: エラーメッセージを読んで学習の機会にする
```
