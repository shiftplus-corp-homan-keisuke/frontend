```typescript

let isActive: boolean = true;

// 2. 型推論の説明（5分）
let inferredString = "Hello"; // string型として推論
let inferredNumber = 42; // number型として推論

// 3. 関数の型注釈（10分）
function greet(name: string): string {
  return `Hello, ${name}!`;
}

// 4. 配列・オブジェクトの型注釈（5分）

let user: { name: string; age: number } = { name: "Alice", age: 30 };
```

**巡回サポートの頻度**: 5分に1回程度、全学習者の進捗確認

## 🤔 よくある質問と推奨回答

### 技術的な質問

**Q1: 「型注釈は必須ですか？」**
**推奨回答**: 
```
TypeScriptは型推論があるので必須ではありませんが、以下の理由で明示的に書くことを推奨します：
- コードの意図が明確になる
- チーム開発で理解しやすくなる
- エラーの早期発見ができる
- IDEの支援が充実する
```

**Q2: 「JavaScriptとの互換性は？」**
**推奨回答**:
```
TypeScriptはJavaScriptのスーパーセットなので：
- 既存のJavaScriptコードはそのまま動作
- 段階的にTypeScript化が可能
- 最終的にはJavaScriptにコンパイルされる
- 既存のライブラリもそのまま使用可能
```

**Q3: 「学習コストは高いですか？」**
**推奨回答**:
```
他言語経験者なら：
- 型システムの概念は理解しやすい
- JavaScript知識があれば習得は早い
- 実際の開発では生産性が向上する
- 大規模開発では必須のスキル
```

### 学習方法に関する質問

**Q4: 「どのくらいの期間で習得できますか？」**
**推奨回答**:
```
学習レベルによって異なりますが：
- 基本的な型注釈: 1-2週間
- 実践的な活用: 1-2ヶ月
- 高度な型システム: 3-6ヶ月
- 継続的な学習が重要です
```

**Q5: 「おすすめの学習リソースは？」**
**推奨回答**:
```
以下のリソースを推奨します：
- TypeScript公式ドキュメント
- TypeScript Playground（実際に試す）
- 既存プロジェクトのTypeScript化
- オープンソースコードの読解
```

#### TypeScriptコンパイルエラー
```typescript
// 問題: 型の不一致
let name: string = 123; // Error

// 解決: 正しい型の使用
let name: string = "Alice"; // OK
```

#### 型推論の誤解
```typescript
// 問題: 型推論への過度な依存
let data = getData(); // any型になる可能性

// 解決: 明示的な型注釈
let data: UserData = getData(); // 型安全
```
