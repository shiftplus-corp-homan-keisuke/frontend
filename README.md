# 学習プラン概要

*   **即戦力フロントエンドエンジニアの実現:**
    *   どの企業でも通用する高度なフロントエンド開発スキルを習得する。
    *   言語、フレームワーク、アーキテクチャ、デザインパターンに精通する。
*   **社内での評価確立:**
    *   シフトプラス社内で「フロントエンドといえば芦澤さん」と認知される存在になる。ヒュ～っ！
*   **具体的目標:**
    *   穂満の当時(2025年5月)の技術レベルを超える。(絶対いける！！)

## 5. 学習方法

今回の提案はベストだと思っているけど唯一の方法ではありません！！
芦澤さんに適したやり方が見つかったら随時方向修正していきます！

*   **学習方法:**
    *   **理論・概要説明:** 穂満が担当。
    *   **コード理解・アウトプット:** 芦澤さんがコードを音読し説明することで、インプットとアウトプットを同時に行います。(所見のコードを理解しながら説明するのって結構脳みそ疲れると思🐰)
*   **各ステップの学習フロー:**
    1.  **理論学習:** 概念や基礎知識を学ぶ。
    2.  **実用例の学習:** 実際の開発現場での活用方法を理解する。
    3.  **実践演習:** 具体的な課題に取り組む。
    4.  **成果物作成:** 学習内容を反映した制作物を完成させる。
*   **成果物の扱い:**
    *   セッション時間内に完成を目指します。
    *   時間内に完了しなかった場合は、該当Phaseの最後にまとめて対応する。
*   **学習環境:**
    *   原則として必要なスキルは全てセッション内で習得できるよう設計。
    *   自宅での予習・復習は不要。
      *   知識、技術の定着は業務中に学習内容の確認のために突然声をかけます。覚えてないことを責めるのではなく忘却曲線が下がりきらないうちに定期的、そして瞬間的にアウトプットすることで長期記憶として定着しやすくします。(人間は20分後には覚えたことの42%を忘れてるんだって！)
