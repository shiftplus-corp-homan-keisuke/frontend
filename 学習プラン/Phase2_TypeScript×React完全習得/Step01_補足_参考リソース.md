## 学習ロードマップ

### Phase 1: 基礎固め（1-2週間）

1. **React 公式チュートリアル**を完了
2. **TypeScript Handbook**の基本部分を読む
3. **React + TypeScript**の基本的なコンポーネントを作成
4. **VS Code 拡張機能**をセットアップ

### Phase 2: 実践開発（2-3週間）

1. **Todo アプリ**を React + TypeScript で作成
2. **React Hook Form**を使ったフォーム作成
3. **React Query**を使った API 連携
4. **React Testing Library**でテスト作成

### Phase 3: 応用・最適化（2-3週間）

1. **パフォーマンス最適化**の実践
2. **カスタムフック**の作成
3. **状態管理ライブラリ**の導入
4. **実際のプロジェクト**への適用
