# Step05-12 セッション分割作業プロンプト

## 📋 作業概要

**目的**: Step01 で実施した 3 セッション分割パターンを、Step05 から Step12 まで全ての Step に統一的に適用する

**対象範囲**: Step05（ジェネリクス基礎）から Step12（ポートフォリオ完成）まで全 8Step

**重要原則**: 各 STEP は必ずそれまでの STEP で学習したことのみで理解できるようにする

## 🎯 統一分割フレームワーク

### 📊 3 セッション構成

```
Session1: [テーマ]理論と基本実践（90分）
├── 📚 理論学習内容
├── 🎯 練習問題（2-3問）
└── 👨‍🏫 学習ポイント

├── 🔧 実用的な実装
├── 🎯 メイン演習プロジェクト
└── 📊 評価基準

Session3: プロジェクト完成（60分）
├── 🎯 最終課題
├── 👨‍🏫 学習ポイント
└── 📊 総合評価
```

3. **実践重視**: 理論だけでなく、実際に動くコードを重視する
