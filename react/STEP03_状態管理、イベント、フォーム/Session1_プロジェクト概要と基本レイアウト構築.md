### 「Far Away」アプリケーションの機能紹介

これは「Far Away」アプリケーションです。次の旅行に必要なアイテムをすべて追加できるシンプルな旅行リストです。

例えば、絶対に忘れてはいけない搭乗券が 2 枚必要だとしましょう。そうすると、Enter キーを押すか、ここをクリックすることができます。

すると、そのアイテムがここのリストに追加されます。また、下の方にある統計情報が更新されたことがわかります。

これだけでも、すでにインタラクティブな機能がありますが、もちろんもっと多くのことができます。

例えば、何らかの理由で充電器がもう必要なくなったとしましょう。そうすると、そこをクリックするだけで削除されます。

また、これらのアイテムを完了済み、つまり基本的にパッキング済みとしてマークすることもできます。

例えば、これとこれをすでにパッキングしたとしましょう。すると、下の方で、すでに 2 つパッキングしたと表示され、それは 50%になります。しかし、さらに多くの機能があります。

ここにある 3 つの項目でソートすることもできます：

- 入力順
- 説明順
- パッキング状況順

そうすると、パッキング済みのアイテムが最後に表示されます。

最後に、旅行から帰ってきて次の旅行の準備をしたいときには、リスト全体を一度にクリアすることができます。

すると、本当に削除してよいかを確認され、「はい」と答えます。

すると、リストが完全に空になります。それだけです。

これは、より多くのインタラクティブ機能を学ぶのに本当に素晴らしい小さなプロジェクトだと思います。構築していくこれらの素晴らしいがシンプルな機能がすべて含まれています。

その上、この素晴らしいデザインも本当に気に入っています。少しレトロな感じで、このアプリケーションの雰囲気に本当によく合っていると思います。

## アイテムリストのレンダリング

前に言ったように、リストのレンダリングは React 開発で最も一般的なタスクの 1 つです。このアプリケーションも例外ではありません。

それでは、パッキングアイテムのリストをレンダリングしましょう。

### 初期データの準備

まず、初期アイテムの配列を準備します。これは学習目的で使用する静的データです。

App.js ファイルの最上部に以下のデータを追加します：

```jsx
const initialItems = [
  { id: 1, description: "Passports", quantity: 2, packed: false },
  { id: 2, description: "Socks", quantity: 12, packed: false },
];
```

この配列には、各パッキングアイテムを表すオブジェクトが含まれています。各オブジェクトには以下のプロパティがあります：

- **id**: 一意の識別子
- **description**: アイテムの説明
- **quantity**: 数量
- **packed**: パッキング済みかどうかのブール値

`packed`プロパティに基づいて、アイテムの表示方法を変更できます。例えば、パッキング済みのアイテムには取り消し線を表示します。

### セマンティック HTML の使用

まず、適切なセマンティック HTML を使用します。リストアイテムを表示するため、ul（順序なしリスト）要素を使用します：

```jsx
function PackingList() {
  return (
    <div className="list">
      <ul>{/* ここにリストアイテムが表示されます */}</ul>
    </div>
  );
}
```

### map メソッドを使用したリストレンダリング

React でリストをレンダリングする方法を覚えていますか？JavaScript の map メソッドを配列で使用します：

```jsx
function PackingList() {
  return (
    <div className="list">
      <ul>
        {initialItems.map((item) => (
          <Item item={item} key={item.id} />
        ))}
      </ul>
    </div>
  );
}
```

**ポイント**：

- `initialItems`配列の各要素に対して Item コンポーネントを生成
- `item`プロパティとして全体のアイテムオブジェクトを渡す
- `key`プロパティには一意の`item.id`を使用（React が効率的に更新するために必要）
- 後でこれを動的なデータに変更していきます

### Item コンポーネントの作成

次に、個別のアイテムを表示する Item コンポーネントを作成します：

```jsx
function Item({ item }) {
  return (
    <li>
      <span>
        {item.quantity} {item.description}
      </span>
    </li>
  );
}
```

**ポイント**：

- props を受け取る際に**分割代入**（destructuring）を使用して`{ item }`とすることで、コードがより読みやすくなります
- `<li>`要素を使用します（`<ul>`の直接の子要素として適切）
- `item.quantity`と`item.description`を表示してアイテム情報を表示

保存すると、「Passports」と「Socks」がリストに表示されます。

### パッキング済みアイテムのスタイリング

仕上げに、そのうちの 1 つをパッキング済みとしてマークしましょう。

これを true にして、追加のスタイリングを追加できるようにします。

基本的に、そこに取り消し線を入れたいと思います。

それは簡単なことです。

Item に来て、ここで条件付きでスタイリングを追加します。

ここでクラスを条件付きで追加する代わりに、条件付きで単純にスタイルを追加したいと思います。

style と書いて、すぐに JavaScript モードに入ります。

しかし、今はすぐに CSS プロパティのオブジェクトを書くのではありません。

代わりに、実際に三項演算子を使用して、スタイルが実際に受け取るべきオブジェクトを決定しましょう。

```jsx
function Item({ item }) {
  return (
    <li>
      <span style={item.packed ? { textDecoration: "line-through" } : {}}>
        {item.quantity} {item.description}
      </span>
      <button>❌</button>
    </li>
  );
}
```

アイテムがパッキングされている場合、ここでは実際に条件は必要ありません。これはすでにブール値だからです。

パッキングされている場合は、取り消し線用の CSS を含むオブジェクトが欲しいですが、そうでない場合、つまりアイテムがパッキングされていない場合は、この空のオブジェクトを返したいと思います。

そうすると、スタイルは適用されません。

探している CSS プロパティは、text decoration と呼ばれ、line through に設定しましょう。このようにです。

そして、それはかなりうまく動作しました。

もう 1 つ試してみましょう。楽しみのために。

そして、すぐに取り消し線も表示されることがわかります。

これは、条件付きでスタイルを設定するために三項演算子を使用するもう 1 つの方法でした。

React では多くの自由があることがわかります。そして、この種のことには、すでに持っている JavaScript ツールを単純に使用します。
