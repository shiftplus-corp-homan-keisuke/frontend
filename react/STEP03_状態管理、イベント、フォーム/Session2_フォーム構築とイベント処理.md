## 制御された要素

Reactのもう一つの基本的な概念である制御された要素について学びましょう。

制御された要素とは何か、そしてReactでフォームを扱うときに制御された要素をどのように使用するかを見てみましょう。

### 制御された要素の概念

まず理解する必要があるのは、デフォルトでは、この入力やこのselectのような入力フィールドは、DOM内で独自の状態を維持するということです。

基本的に、HTML要素自体の内部です。

これにより、それらの値を読み取ることが困難になり、また、この状態をDOM内に残すことになります。これは多くの理由で理想的ではありません。

Reactでは、通常、すべてのこの状態を1つの中央の場所に保持したいと思います。

DOM内ではなく、Reactアプリケーション内です。

そのために、制御された要素と呼ばれる技術を使用します。

この技術により、これらの入力フィールドの状態をReactが制御し、所有し、DOMではなくなります。

### 制御された要素の実装

この技術を実装するために、3つのステップに従います。

まず、状態の一部を作成します。

アプリケーション内にこのデータを保持したいので、それは状態が必要であることを意味します。フォームデータはもちろん時間とともに変化し、アプリケーションをそれと同期させたいからです。

制御された要素技術を実装するために、3つのステップに従います。

まず、状態の一部を作成します。

この実際の入力要素、つまりそこのテキストフィールドから始めましょう。

### 制御された要素の動作原理

それでは、ここで実際に何が起こっているかを理解しましょう。

ユーザーが入力フィールドに何かを入力すると、onChangeイベントが発生します。

そのイベントに応答して、setDescription関数を呼び出して、状態を新しい値に更新します。

状態が更新されると、コンポーネントが再レンダリングされ、入力フィールドに新しい値が表示されます。

これが制御された要素の動作原理です。状態がUIを駆動し、UIの変更が状態を更新します。

### 数量選択の制御された要素化

同じことをselect要素でも行いましょう。

数量用の状態も作成しましょう。

```javascript
const [quantity, setQuantity] = useState(1);
```

デフォルト値は1にします。

そして、select要素に値とonChangeを追加します。

```javascript
<select 
  value={quantity} 
  onChange={(e) => setQuantity(Number(e.target.value))}
>
```

ここで重要なのは、e.target.valueは常に文字列であるため、Number()を使用して数値に変換することです。

```javascript
import { useState } from 'react';

function Form() {
  const [description, setDescription] = useState("");
  const [quantity, setQuantity] = useState(1);

  function handleSubmit(e) {
    e.preventDefault();
    console.log("Form submitted");
  }

  return (
    <form className="add-form" onSubmit={handleSubmit}>
      <h3>What do you need for your 😍 trip?</h3>
      
      <select 
        value={quantity} 
        onChange={(e) => setQuantity(Number(e.target.value))}
      >
        {Array.from({ length: 20 }, (_, i) => i + 1).map((num) => (
          <option value={num} key={num}>
            {num}
          </option>
        ))}
      </select>
      
      <input 
        type="text" 
        placeholder="Item..." 
        value={description}
        onChange={(e) => setDescription(e.target.value)}
      />
      
      <button>Add</button>
    </form>
  );
}
```

これで、両方の入力フィールドが制御された要素になりました。

## まとめ

このセッションでは、以下の重要な概念を学習しました：

1. **フォームの構築**: HTMLフォーム要素を使用してReactでフォームを作成する方法

2. **動的なオプション生成**: Array.fromとmapを使用して、プログラム的にselect要素のオプションを生成する方法

3. **キーの重要性**: リストをレンダリングする際に各要素に一意のキーを提供する必要性

4. **イベント処理**: onSubmitイベントを使用してフォーム送信を処理し、preventDefault()でデフォルトの動作を防ぐ方法

5. **制御された要素**: Reactが入力フィールドの状態を制御し、DOM内ではなくReactアプリケーション内で状態を管理する技術

制御された要素は、Reactでフォームを扱う際の標準的なアプローチです。この技術により、フォームデータを簡単に管理し、バリデーションやその他の操作を実行できます。
