# React フックとそのルール

コースのこの時点で、私たちはすでにいくつかの異なる React フックを使用してきましたが、React フックが実際に何であり、どのように機能するのかを本当に学んだことはありません。

この講義では、それを学びましょう。React フックは、React に組み込まれた特別な関数であり、React の内部メカニズムの一部に「フック」することを可能にします。

言い換えれば、フックとは、Fiber ツリーからの状態の作成とアクセス、または Fiber ツリーでの副作用の登録など、React の内部機能を公開する API です。

繰り返しになりますが、Fiber ツリーは React の奥深くにあるものであり、通常は私たちには全くアクセスできません。しかし、`useState`や`useEffect`フックを使用することで、基本的にその内部メカニズムにフックできます。

さて、フックは、ストア内の DOM ノードを手動で選択したり、コンテキストにアクセスしたり、その他多くのことを可能にします。

さて、すべてのフックに共通しているのは、「use」という単語で始まるということです。これにより、私たちと React が、フックを他の通常の関数と区別しやすくなります。

そして、実際、私たちは「use」という単語で始まる独自の、いわゆるカスタムフックを作成することさえできます。そして、これは一般的にフックに関する最も素晴らしいことの 1 つです。なぜなら、カスタムフックは、開発者が非視覚的なロジック、つまり UI に関するものではないロジックを簡単に再利用する方法を提供するからです。

さて、ご存知かもしれませんが、コンポーネントに状態を与え、コンポーネントのライフサイクルにアクセスしたい場合は、JavaScript クラスに基づいたコンポーネントを使用しなければならなかった時代がありました。

しかし、これにはいくつかの問題があり、React チームはフックを導入しました。そして、今ではフックのおかげで、関数に基づいたコンポーネントは独自のステートを持ち、副作用を実行することもできます。

そして、これは React にとって大きな前進であり、すでに人気があった React をさらに人気にしました。さて、これまでに使用したフックは 2 つだけですが、React には実際には約 20 個の組み込みフックがあります。

では、ここでそれらの簡単な概要を見てみましょう。`useState`と`useEffect`は、もちろん、最も重要なフックの一部であり、したがって、私たちがすぐに学習する`useReducer`と`useContext`とともに、最もよく使用されるフックです。

次に、あまり使用されないフックの巨大なリストがありますが、その中には`useRef`、`useCallback`、`useMemo`のように、実際にはまだ非常に重要なものもあります。

これらのうちのいくつかは学ぶ価値がありますが、他はもう少し曖昧だと思います。したがって、このコースのカリキュラムには含まれていません。

そして最後に、ライブラリ作成者専用のフックがいくつかあります。もちろん、それらについては触れません。さて、フックが意図した通りに実際に機能するためには、私たちが従わなければならない非常に簡単な 2 つのフックのルールがあります。

1 つ目のルールは、フックはトップレベルでのみ呼び出せるということです。つまり、`if`文のような条件分岐の中や、ループの中、コンポーネント内にネストされた関数の中ではフックを呼び出せません。

さて、それはフックが常に全く同じ順序で呼び出された場合にのみ機能するからです。これは、トップレベルで呼び出した場合にのみ保証できます。

# `useState`のまとめ

`useState`フックについて知っていることすべてを 1 枚のスライドにまとめてみましょう。手軽な参照としてお使いいただけます。

`useState`フックは、まず状態を作成し、次に状態を作成した結果であるセッター関数を使用して状態を更新するために使用します。

さて、ほとんどの場合、単純な方法で状態変数を作成できますが、コールバック関数に基づいて状態を作成することもできます。

つまり、ローカルストレージからデータを読み取るなど、初期状態が何らかの計算に依存する場合、単一の値だけでなく、このようなコールバック関数を渡すことができます。

そして、このプロセスは遅延評価と呼ばれることもあります。さて、このコールバック関数はコンポーネントの初期レンダリングでのみ呼び出されるため、その後の再レンダリングでは単純に無視されます。

また、このコールバックは 2 つの要件を満たす必要があります。1 つ目は、純粋な関数であること、2 つ目は、機能するために引数を必要としないことです。

そして、それだけです。これが、`useState`を使用して状態変数を作成する方法です。そして、状態の更新についてですが、繰り返しになりますが、単純な方法で状態を更新できます。

つまり、次の状態として、返されたセッター関数に単一の値を渡すだけです。この例では、次の状態は 1000 になります。

一方、多くの状況では、実際には現在の状態に基づいて状態を更新したい場合があります。たとえば、カウンターを 1 つ増やすなどです。

その場合は、このようにセッター関数にコールバック関数を与えることができます。つまり、純粋で、現在の状態に基づいて次の状態を返す関数です。

そして、私の意見では、これが意味をなす場合は、状態を更新するための好ましい方法です。

さて、状態の更新に関して覚えておくべき重要なルールが 1 つあります。それは、オブジェクトや配列を決して変更してはならないということです。

代わりに、加えたい変更を組み込んだ新しいオブジェクトまたは新しい配列を作成し、その新しいオブジェクトをセッター関数に渡す必要があります。

そして、私たちはすでにそれを何度も行ってきましたが、この要約の講義でもここで言及したかっただけです。

さて、結論として、状態の作成と更新の両方について、単純な方法とコールバック関数を必要とする方法の両方があります。

これは少し混乱を招く可能性があるので、この概要を作成することにしました。これにより、すべてが明確になり、`useState`フックを完全にマスターできたことを願っています。

import { useState } from "react";

function useGeolocation() {
  const [isLoading, setIsLoading] = useState(false);
  const [position, setPosition] = useState({});
  const [error, setError] = useState(null);

  function getPosition() {
    if (!navigator.geolocation)
      return setError("Your browser does not support geolocation");

    setIsLoading(true);
    navigator.geolocation.getCurrentPosition(
      (pos) => {
        setPosition({
          lat: pos.coords.latitude,
          lng: pos.coords.longitude,
        });
        setIsLoading(false);
      },
      (error) => {
        setError(error.message);
        setIsLoading(false);
      }
    );
  }

  return { isLoading, position, error, getPosition };
}

export default function App() {
  const {
    isLoading,
    position: { lat, lng },
    error,
    getPosition,
  } = useGeolocation();

  const [countClicks, setCountClicks] = useState(0);

  function handleClick() {
    setCountClicks((count) => count + 1);
    getPosition();
  }

  return (
    <div>
      <button onClick={handleClick} disabled={isLoading}>
        Get my position
      </button>

      {isLoading && <p>Loading position...</p>}
      {error && <p>{error}</p>}
      {!isLoading && !error && lat && lng && (
        <p>
          Your GPS position:{" "}
          <a
            target="_blank"
            rel="noreferrer"
            href={`https://www.openstreetmap.org/#map=16/${lat}/${lng}`}
          >
            {lat}, {lng}
          </a>
        </p>
      )}

      <p>You requested position {countClicks} times</p>
    </div>
  );
}
