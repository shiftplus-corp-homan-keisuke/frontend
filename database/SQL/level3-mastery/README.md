# データベーススペシャリスト試験 SQL学習教材
## Level 3: Mastery（上級レベル）

## 概要

このディレクトリには、データベーススペシャリスト試験に向けたSQL上級レベルの学習教材が含まれています。中級SQL理解者を対象とし、高度なウィンドウ関数・再帰クエリ・ストアドプロシージャ・トランザクション制御・パフォーマンス最適化まで、実務レベルのスキルを段階的に習得できるよう設計されています。

## 対象者

- Level 2: Application（中級レベル）を修了した方
- 外部結合、サブクエリ、基本的なウィンドウ関数を理解している方
- データベーススペシャリスト試験の上級問題に挑戦したい方
- 実務レベルのSQL技術を習得したい方
- データベース設計・最適化に関わる方

## 学習目標

- 高度なウィンドウ関数（LAG、LEAD、FIRST_VALUE、LAST_VALUE、NTILE）の習得
- 再帰クエリ（WITH RECURSIVE）による階層データ処理
- 共通テーブル式（CTE）の高度な活用
- ストアドプロシージャとファンクションの設計・実装
- トリガーとイベント処理による自動化
- トランザクション制御（ACID特性、分離レベル）の理解と実装
- 高度なパフォーマンス最適化技術
- 実行計画の読み方と分析による最適化
- データベース設計の実践（正規化、非正規化、パーティショニング）
- データベーススペシャリスト試験の上級問題対策

## 学習期間・合格基準

- **学習期間**: 4-5週間
- **合格基準**: 80点以上
- **前提条件**: Level 2: Application（中級レベル）の合格
- **次のレベル**: 実務プロジェクトでの実践・専門分野への特化

## 学習の進め方

### ステップ1: 理論学習（推奨期間: 2週間）
1. **[`theory.md`](./theory.md)** を読んで上級理論を学習
2. 各セクションの確認問題を解いて理解度をチェック
3. 中級レベルの内容を前提とした高度な内容を重点的に学習
4. 実際のデータベース環境で実践例を実行して動作確認
5. 不明な点があれば該当セクションを再読し、必要に応じて中級レベルに戻る

### ステップ2: 実践練習（推奨期間: 2週間）
1. **[`practice.md`](./practice.md)** の練習問題に挑戦
2. セクション1から順番に進める（基礎から応用へ段階的に）
3. 複雑な問題も段階的に分解して理解
4. **[`solutions.md`](./solutions.md)** で解答と解説を確認
5. 間違えた問題は理論に戻って復習し、類似問題で再確認
6. パフォーマンス測定と最適化を実践

### ステップ3: 習熟度確認（推奨期間: 1週間）
1. **[`test.md`](./test.md)** で習熟度テストを実施
2. 150分の制限時間を設けて本番形式で挑戦
3. 80点以上で合格、実務レベルのSQL技術習得完了
4. 不合格の場合は弱点分野を重点的に復習

## 学習のコツ

### 効果的な学習方法
1. **中級の確実な理解**: Level 2の内容を完全に理解してから進む
2. **実践重視**: 理論学習後は必ず実際のデータベースで実行
3. **段階的な学習**: 複雑な問題も基本要素に分解して理解
4. **パフォーマンス意識**: 常に実行計画を確認し最適化を考慮
5. **反復学習**: 間違えた問題は時間を置いて再度挑戦
6. **実環境での実習**: 大量データでの動作確認とパフォーマンス測定

### よくある躓きポイント
1. **高度なウィンドウ関数**: LAG/LEADの適切な使用とパフォーマンス
2. **再帰クエリの理解**: WITH RECURSIVEの動作原理と終了条件
3. **ストアドプロシージャの設計**: 適切な例外処理とトランザクション制御
4. **トランザクション分離レベル**: 各レベルの特徴と適用場面
5. **実行計画の読み方**: コストベース最適化の理解
6. **インデックス設計**: 複合インデックスの効果的な設計

### エラーが発生した場合
1. **構文エラー**: 複雑なSQL文の括弧、クォート、セミコロンの確認
2. **論理エラー**: 期待した結果が得られない場合は段階的にデバッグ
3. **パフォーマンス問題**: 実行計画を確認し、適切なインデックスを検討
4. **デッドロック**: トランザクションの順序と分離レベルを見直し
5. **メモリ不足**: 大量データ処理時のメモリ使用量を最適化

## 推奨学習環境

### データベース管理システム
- **PostgreSQL** 13以上（推奨：WITH RECURSIVE、高度なウィンドウ関数サポート）
- **MySQL** 8.0以上（ウィンドウ関数、CTE、再帰クエリサポート）
- **Oracle Database** 19c以上（Express Edition可、高度な機能フルサポート）
- **SQL Server** 2019以上（Express Edition可、高度な機能サポート）
- **SQLite** 3.35以上（一部機能制限あり、学習用途）

### 学習ツール
- **pgAdmin**（PostgreSQL用、推奨）
- **DBeaver**（汎用データベースツール、実行計画表示）
- **MySQL Workbench**（MySQL用、パフォーマンス分析）
- **SQL Server Management Studio**（SQL Server用）
- **Oracle SQL Developer**（Oracle用）

### 推奨データセット
- **大規模サンプルデータベース**: PostgreSQL Sample Database、MySQL Employees Database
- **実践データ**: 売上データ（100万件以上）、顧客データ、在庫データなど
- **階層データ**: 組織構造、カテゴリ階層、地理的階層データ
