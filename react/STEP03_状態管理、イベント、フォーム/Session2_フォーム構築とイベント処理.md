## 制御された要素

React のもう一つの基本的な概念である制御された要素について学びましょう。

制御された要素とは何か、そして React でフォームを扱うときに制御された要素をどのように使用するかを見てみましょう。

### 制御された要素の概念

まず理解する必要があるのは、デフォルトでは、この入力やこの select のような入力フィールドは、DOM 内で独自の状態を維持するということです。

HTML 要素自体の内部です。

これにより、それらの値を読み取ることが困難になり、また、この状態を DOM 内に残すことになります。これは多くの理由で理想的ではありません。

React では、通常、すべてのこの状態を 1 つの中央の場所に保持したいと思います。

DOM 内ではなく、React アプリケーション内です。

そのために、制御された要素と呼ばれる技術を使用します。

この技術により、これらの入力フィールドの状態を React が制御し、所有し、DOM ではなくなります。

この技術を実装するために、3 つのステップに従います。

### 制御された要素の動作原理

それでは、ここで実際に何が起こっているかを理解しましょう。

ユーザーが入力フィールドに何かを入力すると、`onChange`イベントが発生します。

そのイベントに応答して、`setDescription`関数を呼び出して、状態を新しい値に更新します。

状態が更新されると、コンポーネントが再レンダリングされ、入力フィールドに新しい値が表示されます。

これが制御された要素の動作原理です。状態が UI を駆動し、UI の変更が状態を更新します。

### 数量選択の制御された要素化

同じことを select 要素でも行いましょう。

数量用の状態も作成しましょう。

```javascript
const [quantity, setQuantity] = useState(1);
```

デフォルト値は 1 にします。

そして、select 要素に値と onChange を追加します。

```javascript
<select
  value={quantity}
  onChange={(e) => setQuantity(Number(e.target.value))}
>
```

ここで重要なのは、e.target.value は常に文字列であるため、Number()を使用して数値に変換することです。

```javascript
import { useState } from "react";

function Form() {
  const [description, setDescription] = useState("");
  const [quantity, setQuantity] = useState(1);

  function handleSubmit(e) {
    e.preventDefault();
    console.log("Form submitted");
  }

  return (
    <form className="add-form" onSubmit={handleSubmit}>
      <h3>What do you need for your 😍 trip?</h3>

      <select
        value={quantity}
        onChange={(e) => setQuantity(Number(e.target.value))}
      >
        {Array.from({ length: 20 }, (_, i) => i + 1).map((num) => (
          <option value={num} key={num}>
            {num}
          </option>
        ))}
      </select>

      <input
        type="text"
        placeholder="Item..."
        value={description}
        onChange={(e) => setDescription(e.target.value)}
      />

      <button>Add</button>
    </form>
  );
}
```

これで、両方の入力フィールドが制御された要素になりました。

## まとめ

このセッションでは、以下の重要な概念を学習しました：

1. **フォームの構築**: HTML フォーム要素を使用して React でフォームを作成する方法

2. **動的なオプション生成**: Array.from と map を使用して、プログラム的に select 要素のオプションを生成する方法

制御された要素は、React でフォームを扱う際の標準的なアプローチです。この技術により、フォームデータを簡単に管理し、バリデーションやその他の操作を実行できます。
