## 📚 セッション別指導ポイント

### Session1 指導ポイント（90 分）

#### 🎯 重点サポート箇所

**1. ユニオン型の概念理解（10-30 分）**

- **よくある誤解**: 「ユニオン型は全ての型のプロパティにアクセスできる」
- **正しい理解**: 「共通のプロパティのみアクセス可能」
- **指導方法**: 実際にエラーを見せて、なぜエラーになるかを説明

```typescript
// 誤解例を実演
function badExample(value: string | number) {
  return value.toUpperCase(); // エラーになることを実演
}

// 正しい例を実演
function goodExample(value: string | number) {
  if (typeof value === "string") {
    return value.toUpperCase(); // 型ガード後は安全
  }
  return value.toString();
}
```

**2. インターセクション型の理解（30-40 分）**

- **重要ポイント**: ユニオン型（|）との違いを明確に
- **実演方法**: 実際のオブジェクトを作成して違いを体感させる

**3. 基本的な型ガード（50-80 分）**

- **つまずきポイント**: typeof の返り値を正確に覚えていない
- **サポート方法**: typeof の返り値一覧を提示し、実際に確認させる

#### 🕐 時間管理のコツ

- **10-30 分**: 概念説明は簡潔に、実演重視
- **30-50 分**: 手を動かす時間を多く確保
- **50-80 分**: 個別サポートに重点、理解度に応じて調整
- **80-90 分**: 次回への期待感を高める予告

#### ❓ よくある質問と推奨回答

**Q1: 「ユニオン型とオプショナルプロパティの違いは？」**

```typescript
// オプショナルプロパティ（Step03で学習済み）
interface User {
  name: string;
  age?: number; // number | undefined
}

// ユニオン型
type StringOrNumber = string | number;
```

**A1**: 「オプショナルプロパティは `T | undefined` のシンタックスシュガーです。ユニオン型はより一般的な概念で、任意の型を組み合わせられます。」

**Q2: 「いつインターセクション型を使うべき？」**
**A2**: 「既存の型に機能を追加したい場合です。例えば、基本の User にタイムスタンプを追加する場合などです。」

**Q3: 「型ガードを書くのが面倒です」**
**A3**: 「最初は面倒に感じますが、実行時エラーを防ぐ重要な仕組みです。慣れると自然に書けるようになります。」

## ❓ よくある質問と推奨回答

### 技術的な質問

**Q1: 「ユニオン型とジェネリクスの違いは？」**
**A1**: 「ユニオン型は具体的な型の組み合わせ、ジェネリクスは型のパラメータ化です。ジェネリクスは Step05 で詳しく学習します。」

**Q2: 「型ガードを関数にまとめる方法は？」**

```typescript
function isString(value: unknown): value is string {
  return typeof value === "string";
}
```

**A2**: 「このような型述語関数を作成できます。Step05 でより詳しく学習します。」

**Q3: 「実際のプロジェクトでどこまで型ガードを書くべき？」**
**A3**: 「外部からのデータ（API、ユーザー入力）を扱う境界で必ず書きましょう。内部の型安全な処理では不要です。」

### 学習方法に関する質問

**Q4: 「型エラーが多くて進まない」**
**A4**: 「最初は正常です。エラーメッセージをよく読んで、一つずつ解決していきましょう。型エラーは実行時エラーを防ぐ味方です。」

**Q5: 「どの型ガードを使うべきか迷う」**
**A5**: 「プリミティブ型なら typeof、クラスなら instanceof、オブジェクトのプロパティなら in 演算子が基本です。」

## 🎯 指導上の注意事項

### 学習者の背景への配慮

**他言語経験者の特徴**:

- 型システムの概念は理解している
- JavaScript の動的な性質に慣れていない場合がある
- 静的型付け言語の経験があるため、型ガードの必要性を理解しやすい

**指導時の配慮点**:

- JavaScript 特有の動的な性質を説明
- 他言語との違いを明確に
- 実践的な例を多用して理解を促進

### 進度調整のポイント

**早く進む学習者への対応**:

- 応用的な課題を提供

- Step05 の内容を少し紹介

**遅れがちな学習者への対応**:

- 基本概念の再確認
- 簡単な例から段階的に
- 個別の時間を多く確保

### 学習環境の整備

**推奨設定**:

- TypeScript strict モードを有効化
- エディタの型エラー表示を確認
- 実行環境（Node.js + ts-node）の準備
