## 🚀 プロジェクト実装ガイド

### 📋 実装要件

#### 必須機能

1. **プロジェクト設定とヘッダー**:
   - 使用技術: Vite, React, TypeScript
   - 実装ポイント: `npm create vite@latest` でプロジェクトを初期化し、`Header` コンポーネントを作成して `App.tsx` に組み込む。`props` でタイトルを渡す。
2. **メニューとピザコンポーネント**:
   - 使用技術: React コンポーネント、TypeScript `interface`, `Array.prototype.map()`
   - 実装ポイント: `pizzaData.ts` でピザデータを定義し、`Menu` コンポーネントで `pizzaData` をマップして `Pizza` コンポーネントをレンダリングする。`Pizza` コンポーネントは `pizzaObj` を `props` で受け取る。
3. **売り切れ表示と条件付きレンダリング**:
   - 使用技術: 条件付きレンダリング（三項演算子、論理 AND 演算子）
   - 実装ポイント: `Pizza` コンポーネントで `soldOut` プロパティに基づいて「SOLD OUT」表示と価格表示を切り替える。売り切れピザには特別な CSS クラスを適用する。
4. **開店/閉店メッセージと注文ボタン**:
   - 使用技術: JavaScript `Date` オブジェクト、条件付きレンダリング
   - 実装ポイント: `Footer` コンポーネントで現在の時間に基づいて開店/閉店を判定し、メッセージと注文ボタンを条件付きで表示する。閉店時はボタンを無効化する。
5. **アプリケーション全体のスタイリング**:
   - 使用技術: CSS Modules (または通常の CSS)
   - 実装ポイント: `App.css` や各コンポーネントの CSS ファイルで、アプリケーション全体に統一感のあるデザインを適用する。

#### 技術要件

- **TypeScript**: `props` の型定義、データ構造の型定義など、この STEP で学んだ型活用パターンを適切に適用すること。
- **React**: コンポーネントの分割、`props` を使ったデータフロー、条件付きレンダリングなど、この STEP で学んだ React パターンを実践すること。
- **品質**: コードの可読性、保守性、型安全性を意識して実装すること。

## 🗒️ プロジェクト完成まとめ

### ✅ 完成した機能

- **ヘッダーコンポーネント**: `props` でタイトルを受け取り表示。
- **メニューコンポーネント**: ピザデータのリストをマップして `Pizza` コンポーネントをレンダリング。ピザがない場合は代替メッセージを表示。

- **フッターコンポーネント**: 現在の営業時間に基づいて開店/閉店メッセージを表示し、開店時のみ注文ボタンを有効化。
- **全体スタイリング**: アプリケーション全体に統一されたデザインを適用。

### 📈 習得できたスキル

- React + TypeScript + Vite を用いたプロジェクトの初期設定と開発フロー
- コンポーネントの適切な分割と `props` を使ったデータフローの設計
- TypeScript による `props` とデータ構造の厳格な型定義
- 条件付きレンダリングの様々なパターンと実践的な応用
- CSS Modules を使ったコンポーネントスコープのスタイリング
