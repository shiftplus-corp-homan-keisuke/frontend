# エフェクトの初見

コンポーネントがマウントされるときに映画のデータを取得するために、初めて`used effect`フックを使用しました。

しかし、実際にはエフェクトとは何で、イベントハンドラー関数とはどのように違うのでしょうか？さて、このビデオで調べてみましょう。

そして、皆さんが同じ認識を持つように、まず副作用とは何かを復習することから始めましょう。基本的にReactでは、副作用とは、Reactコンポーネントとコンポーネント外の世界との間のあらゆる相互作用のことです。

そして、副作用を、実際に何か役立つことを起こすコードと考えることができます。例えば、APIからデータを取得することなどです。

つまり、Reactアプリを構築するときは、常に副作用が必要だということです。さて、副作用はコンポーネントのレンダリング中に発生すべきではない、言い換えれば、副作用はレンダリングロジックにあるべきではないことはすでに知っています。

代わりに、Reactでは2つの異なる場所で副作用を作成できます。1つ目はイベントハンドラー内です。

そして、イベントハンドラーとは、リッスンしているイベントが発生するたびにトリガーされる単なる関数であることを思い出してください。

しかし、イベントに単に反応するだけでは、アプリケーションが必要とするものには十分ではない場合があります。代わりに、状況によっては、コンポーネントがレンダリングされると自動的に実行されるコードを記述する必要があります。

そして、`useEffect`フックを使用して、いわゆる「エフェクト」を作成できるのはこのときです。

エフェクトを作成することで、コンポーネントインスタンスのライフサイクルのさまざまな時点で実行されるコードを基本的に記述できます。コンポーネントがマウントされるとき、再レンダリングされるとき、さらにはアンマウントされるときです。

これは、まったく新しい可能性の扉を開くため、本当に素晴らしいことです。さて、ではイベントハンドラーを`useEffect`フックで作成されたエフェクトと比較することで、エフェクトがどのように機能するかについてもう少し深く掘り下げてみましょう。

そして、私たちが使ってきた映画のデータを取得する例に戻りましょう。映画のデータを取得することは、コンポーネント外の世界との相互作用であるため、明らかに副作用です。

さて、この副作用を作成したいと思う可能性がある2つの異なる可能性があります。1つ目は、特定のイベントが発生したときにのみ映画のデータを取得したいと思うかもしれないということです。

その場合、もちろんイベントハンドラー関数を使用するだけです。これまでやってきたように、イベントハンドラーを使用してデータを取得したことはありませんが、他のことに使用してきました。

さて、データをいつ取得するかのもう一つの可能性は、コンポーネントがマウントされた直後、つまり最初にレンダリングされた後に行うことです。

そして、これはまさに前回の講義で、コンポーネントが画面に描画された直後に実行されたエフェクトを指定するために初めて`use event`を使用したときに行ったことです。

// `https://api.frankfurter.app/latest?amount=100&from=EUR&to=USD`

import { useEffect, useState } from "react";

export default function App() {
  const [amount, setAmount] = useState(1);
  const [fromCur, setFromCur] = useState("EUR");
  const [toCur, setToCur] = useState("USD");
  const [converted, setConverted] = useState("");
  const [isLoading, setIsLoading] = useState(false);

  useEffect(
    function () {
      async function convert() {
        setIsLoading(true);
        const res = await fetch(
          `https://api.frankfurter.app/latest?amount=${amount}&from=${fromCur}&to=${toCur}`
        );
        const data = await res.json();
        setConverted(data.rates[toCur]);
        setIsLoading(false);
      }

      if (fromCur === toCur) return setConverted(amount);
      convert();
    },
    [amount, fromCur, toCur]
  );

  return (
    <div>
      <input
        type="text"
        value={amount}
        onChange={(e) => setAmount(Number(e.target.value))}
        disabled={isLoading}
      />
      <select
        value={fromCur}
        onChange={(e) => setFromCur(e.target.value)}
        disabled={isLoading}
      >
        <option value="USD">USD</option>
        <option value="EUR">EUR</option>
        <option value="CAD">CAD</option>
        <option value="INR">INR</option>
      </select>
      <select
        value={toCur}
        onChange={(e) => setToCur(e.target.value)}
        disabled={isLoading}
      >
        <option value="USD">USD</option>
        <option value="EUR">EUR</option>
        <option value="CAD">CAD</option>
        <option value="INR">INR</option>
      </select>
      <p>
        {converted} {toCur}
      </p>
    </div>
  );
}
