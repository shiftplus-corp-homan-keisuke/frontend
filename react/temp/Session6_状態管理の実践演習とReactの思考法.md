### プロジェクト概要と動作デモ

早速始めていきましょう。

これから構築するのは、フラッシュカードアプリケーションです。実際には小さなプロジェクトと言えるでしょう。

フラッシュカードとは、基本的に片面に質問があり、クリックすると反対面に答えが表示されるカードのことです。

多くの人が学習に使用している、カードを回転させるようなイメージです。

このアプリケーションの動作を詳しく説明しましょう：

- カードをクリックすると、質問から答えに切り替わります

これは楽しい小さな演習になります。今は複雑に見えるかもしれませんが、**たった一つの状態**ですべてを制御できます。

### 完全なコンポーネント実装

```jsx
import { useState } from "react";
import "./styles.css";

export default function App() {
  return (
    <div className="App">
      <Counter />
    </div>
  );
}

function Counter() {
  const [count, setCount] = useState(0);
  const [step, setStep] = useState(1);

  function handleReset() {
    setCount(0);
    setStep(1);
  }

  const date = new Date("june 21 2027");
  date.setDate(date.getDate() + count);

  return (
    <div>
      <div>
        <input
          type="range"
          min="0"
          max="10"
          value={step}
          onChange={(e) => setStep(Number(e.target.value))}
        />
        <span>Step: {step}</span>
      </div>

      <div>
        <button onClick={() => setCount((c) => c - step)}>-</button>
        <input
          type="text"
          value={count}
          onChange={(e) => setCount(Number(e.target.value))}
        />
        <button onClick={() => setCount((c) => c + step)}>+</button>
      </div>

      <p>
        <span>
          {count === 0
            ? "Today is "
            : count > 0
            ? `${count} days from today is `
            : `${Math.abs(count)} days ago was `}
        </span>
        <span>{date.toDateString()}</span>
      </p>

      {count !== 0 || step !== 1 ? (
        <div>
          <button onClick={handleReset}>Reset</button>
        </div>
      ) : null}
    </div>
  );
}
```

## React の思考法とは何か？

### React の思考法の核心

セクションを開始するために、React の思考法が実際に何についてのものかを発見しましょう。

今までに気づいたかもしれませんが、React アプリケーションの構築には完全に新しい考え方が必要です。

なぜなら、バニラ JavaScript でアプリケーションを構築するのとは非常に異なるからです。

React アプリを構築するには、useState のようなすべての異なる関数で React API を実際に使用する方法を学ぶだけでなく、React で考えることもできる必要があります。

基本的に React の考え方に入る必要があります。

これら両方のスキルを持つと、React をマスターし、プロフェッショナルな React アプリケーションを構築する道を順調に進むことができます。

React で考えるとは実際に何を意味するのでしょうか？

アプリケーションを構築している間、React で考えるということは、コンポーネント、状態、プロパティ、一般的なデータフロー、エフェクトなど、すべての React ツールをいつ、どのように使用するかについて非常に良いメンタルモデルを持っていることを意味します。

また、以前に学んだように、要素の変更ではなく、常に状態の遷移の観点から考えることでもあります。

### React の思考法のプロセス

React の思考法を、より構造化された方法でアプリを構築するのに役立つ全体的なプロセスとして見ることもできます。

このプロセスの最初のステップは、望ましい UI をコンポーネントに分割し、これらのコンポーネントが互いにどのように関連しているかを確立することです。

つまり、コンポーネントツリーを確立することです。

これには、コンポーネントの再利用性と構成可能性について考えることも含まれます。

その後、アプリケーションの静的バージョンの構築を開始できます。

状態やインタラクティビティなしで、これは素晴らしいことです。

なぜなら、これを行うことで、状態やインタラクティビティについて心配する前に、ほとんどのコーディングを前もって行うからです。

その部分は次に来ます。

#### 1. UI をコンポーネントに分割
