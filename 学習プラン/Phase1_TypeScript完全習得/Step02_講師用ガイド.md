# Step02 講師用指導ガイド

> 💡 **このガイドについて**: Step02の3セッション構成での効果的な指導方法をまとめた講師向けの詳細ガイドです。

## 🎯 指導方針

### 対象学習者
- **他言語経験者**（Java、C#、Python等の静的型付け言語経験あり）
- **Step01完了者**（TypeScript基本構文の理解済み）
- **型システムの概念理解**（静的型付けの価値を理解している）

### 指導スタイル
- **型学習特化**: ロジック実装よりも型システムの理解に重点
- **実践重視**: 理論説明は簡潔に、実践時間を最大化
- **段階的習得**: 基本型→複合型→型設計の確実なステップアップ

### 学習成果目標
- TypeScript型システムの実践的理解
- 型安全なデータ構造設計能力
- 実際のプロジェクトで使える型定義スキル

**講師の準備**:

- [ ] TypeScript Playground の動作確認
- [ ] 型エラーの実演準備

**指導ポイント**:
```
1. Step01復習（3分）
```

**よくある質問と回答**:
- **Q**: 「JavaのStringとTypeScriptのstringの違いは？」
- **A**: 「TypeScriptのstringはプリミティブ型で、リテラル型も使用可能。より柔軟で軽量です」

##### 型システム理論学習時（10-50分）：実演・解説・個別サポート

**指導の重点**:
1. **プリミティブ型の理解**（15分）
   - string, number, boolean, null, undefined の使い分け
   - リテラル型の強力さを実演
   - 他言語との比較で理解促進

2. **型推論の仕組み**（15分）
   - let vs const の型推論の違いを実演
   - 型推論の利点と限界
   - 明示的型注釈が必要な場面

3. **実践的な活用例**（10分）
   - API レスポンスの型定義
   - 設定管理での型活用
   - エラーハンドリングでの型安全性

**実演のコツ**:
- TypeScript Playground で型推論結果をリアルタイム表示
- 意図的に型エラーを発生させて解決方法を示す
- 他言語経験者向けに比較説明を多用

**サポート対象**:
- 型推論の仕組みに戸惑う学習者
- リテラル型の概念が理解できない学習者
- null/undefined の使い分けに迷う学習者

## 💡 指導上の重要ポイント

### 他言語経験者向けの配慮

**Java/C#経験者向け**:
- 構造的型付け vs 名前的型付けの違いを強調
- インターフェースの継承概念の違いを説明
- ジェネリクスの記法の違いを比較

**Python経験者向け**:
- 動的型付けから静的型付けへの思考転換をサポート
- 型ヒントとの違いを説明
- より厳密な型チェックの利点を実演

### よくある質問と推奨回答

**Q**: 「いつ明示的な型注釈が必要ですか？」
**A**: 「型推論が不十分な場合、API境界、複雑な型構造の場合です。実例を見せながら説明しましょう」

**Q**: 「interfaceとtypeの使い分けは？」
**A**: 「拡張性が必要ならinterface、Union型や計算型が必要ならtypeです。具体例で示しましょう」

**Q**: 「実際のプロジェクトではどこまで型を定義すべきですか？」
**A**: 「API境界、重要なデータ構造、エラーが起きやすい箇所は必須です。段階的に拡張していく方法を説明しましょう」

### 時間管理のコツ

**Session1**:
- 理論説明は簡潔に（各項目5-10分以内）
- 実践時間を十分確保（30分）
- 個別サポートを積極的に実施

**Session2**:
- 演習時間を最大化（70分）
- 複雑な概念は実例で説明
- 成果共有で学習効果を高める

**Session3**:
- プロジェクト時間を確実に確保（35分）
- 発表時間を必ず設ける（15分）
- 次Stepへの準備を忘れずに

## 🔧 トラブルシューティング

### よくある問題と対処法

**型エラーが理解できない**:
- エラーメッセージの読み方を段階的に指導
- TypeScript Playground での確認方法を実演
- 簡単な例から複雑な例へ段階的に説明

**型推論の結果が予想と違う**:
- 型推論のルールを具体例で説明
- hover機能での型確認方法を指導
- 明示的型注釈での解決方法を提示

**複雑な型定義が作成できない**:
- 小さな型から段階的に組み立てる方法を指導
- 既存の型定義例を参考にする方法を提示
- ユーティリティ型の活用方法を実演

### 学習進度の調整

**進度が早い学習者**:
- 発展的な課題を提供
- 他の学習者のサポート役を依頼
- より高度な型機能の紹介

**進度が遅い学習者**:
- 個別サポートを重点的に実施
- 基本概念の再確認
- 簡単な例から段階的に理解を促進
