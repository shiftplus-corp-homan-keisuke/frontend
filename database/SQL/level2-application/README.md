# データベーススペシャリスト試験 SQL学習教材
## Level 2: Application（中級レベル）

## 概要

このディレクトリには、データベーススペシャリスト試験に向けたSQL中級レベルの学習教材が含まれています。基本SQL理解者を対象とし、高度な結合・サブクエリ・制御構文・ビューと制約まで、実践的なスキルを段階的に習得できるよう設計されています。

## 対象者

- Level 1: Foundation（基礎レベル）を修了した方
- 基本的なSELECT文、集約関数、内部結合を理解している方
- データベーススペシャリスト試験の中級問題に挑戦したい方
- より実践的なSQL技術を習得したい方

## 学習目標

- 外部結合（LEFT JOIN、RIGHT JOIN、FULL OUTER JOIN）の理解と実装
- サブクエリと相関サブクエリの効果的な活用
- CASE文とCOALESCE関数による条件分岐処理
- ウィンドウ関数の基礎（ROW_NUMBER、RANK、DENSE_RANK）の習得
- ビューの作成と活用による効率的なデータアクセス
- 制約（PRIMARY KEY、FOREIGN KEY、CHECK制約）の理解と実装
- インデックスの基本概念とパフォーマンス最適化

## 学習期間・合格基準

- **学習期間**: 3-4週間
- **合格基準**: 70点以上
- **前提条件**: Level 1: Foundation（基礎レベル）の合格
- **次のレベル**: Level 3: Advanced（上級レベル）

## 学習の進め方

### ステップ1: 理論学習（推奨期間: 1.5週間）
1. **[`theory.md`](./theory.md)** を読んで中級理論を学習
2. 各セクションの確認問題を解いて理解度をチェック
3. 基礎レベルの内容を前提とした発展的な内容を重点的に学習
4. 不明な点があれば該当セクションを再読し、必要に応じて基礎レベルに戻る

### ステップ2: 実践練習（推奨期間: 1.5週間）
1. **[`practice.md`](./practice.md)** の練習問題に挑戦
2. セクション1から順番に進める（基礎から応用へ段階的に）
3. 複雑な問題も一度は自分で考えてから解答を確認
4. **[`solutions.md`](./solutions.md)** で解答と解説を確認
5. 間違えた問題は理論に戻って復習し、類似問題で再確認

### ステップ3: 習熟度確認（推奨期間: 1週間）
1. **[`test.md`](./test.md)** で習熟度テストを実施
2. 120分の制限時間を設けて本番形式で挑戦
3. 70点以上で合格、次のレベルへ進級可能
4. 不合格の場合は弱点分野を重点的に復習

## 各ファイルの詳細

### 📚 theory.md（理論学習）
- **内容**: SQL中級の包括的な理論解説
- **構成**: 概要・目標・解説・実践例・試験ポイント・確認問題
- **学習項目**:
  - 外部結合の種類と使い分け
  - サブクエリと相関サブクエリの効果的な活用
  - CASE文による条件分岐とCOALESCE関数
  - ウィンドウ関数の基礎と実践的な使用方法
  - ビューの作成・更新・削除と活用方法
  - 制約の種類と実装方法
  - インデックスの基本概念とパフォーマンス最適化

### 💪 practice.md（練習問題）
- **内容**: 段階的に難易度が上がる実践問題
- **問題数**: 約60問（8セクション + 応用問題）
- **特徴**:
  - 実際のビジネスシナリオを想定した実践的な問題
  - 基礎から応用まで段階的な構成
  - データベーススペシャリスト試験の中級問題に対応
  - 複数の解法を要求する問題も含む

### 📖 solutions.md（解答・解説）
- **内容**: 全練習問題の詳細な解答と解説
- **特徴**:
  - SQL文の構文説明と実行計画の考察
  - 実行結果の予想と検証
  - 学習ポイントの明確化
  - 複数の解法の提示（該当する場合）
  - よくある間違いとその対処法
  - パフォーマンス最適化のヒント

### 📝 test.md（習熟度テスト）
- **形式**: 選択式問題（25問）
- **時間**: 120分
- **配点**: 各問4点（合計100点）
- **合格基準**: 70点以上（18問以上正解）
- **特徴**:
  - データベーススペシャリスト試験の出題形式に準拠
  - 中級から応用まで幅広い範囲をカバー
  - 実践的なシナリオベースの問題
  - 詳細な採点基準と学習アドバイス

## 学習のコツ

### 効果的な学習方法
1. **基礎の確実な理解**: Level 1の内容を完全に理解してから進む
2. **実践重視**: 理論学習後は必ず実践問題で確認
3. **段階的な学習**: 複雑な問題も基本要素に分解して理解
4. **反復学習**: 間違えた問題は時間を置いて再度挑戦
5. **実環境での実習**: 可能であれば実際のデータベースで実行して動作確認

### よくある躓きポイント
1. **外部結合の理解**: LEFT JOINとRIGHT JOINの違いと使い分け
2. **サブクエリの最適化**: 相関サブクエリのパフォーマンス問題
3. **ウィンドウ関数の構文**: PARTITION BYとORDER BYの適切な使用
4. **制約の設計**: 適切な制約の選択と実装方法
5. **インデックスの効果**: どの列にインデックスを作成すべきか

### エラーが発生した場合
1. **構文エラー**: 複雑なSQL文の括弧、クォート、セミコロンの確認
2. **論理エラー**: 期待した結果が得られない場合は結合条件を再確認
3. **パフォーマンス問題**: 実行計画を確認し、適切なインデックスを検討
4. **制約エラー**: データの整合性を確認し、制約の設計を見直し

## 推奨学習環境

### データベース管理システム
- **MySQL** 8.0以上（ウィンドウ関数サポート）
- **PostgreSQL** 13以上
- **SQLite** 3.35以上（一部ウィンドウ関数制限あり）
- **Oracle Database** 19c以上（Express Edition可）
- **SQL Server** 2019以上（Express Edition可）

### 学習ツール
- **phpMyAdmin**（MySQL用）
- **pgAdmin**（PostgreSQL用）
- **DBeaver**（汎用データベースツール）
- **MySQL Workbench**（MySQL用）
- **SQL Server Management Studio**（SQL Server用）

### 推奨データセット
- **サンプルデータベース**: Northwind、Sakila、Chinook
- **実践データ**: 売上データ、顧客データ、在庫データなど
