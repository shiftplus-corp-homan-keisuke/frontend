# データベーススペシャリスト試験 SQL学習教材
## Level 1: Foundation（基礎レベル）

## 概要

このディレクトリには、データベーススペシャリスト試験に向けたSQL基礎レベルの学習教材が含まれています。SQL完全初心者を対象とし、基本的なデータ操作から内部結合まで、段階的に学習できるよう設計されています。

## 対象者

- SQL完全初心者
- データベーススペシャリスト試験の受験を検討している方
- 基本的なデータベース操作を学習したい方

## 学習目標

- 基本SELECT文（WHERE、ORDER BY、LIMIT）の習得
- 集約関数（COUNT、SUM、AVG、MAX、MIN）の理解と活用
- GROUP BY、HAVING句を使用した条件付き集計
- 基本的な内部結合（INNER JOIN）の実装
- 基本的なデータ操作（INSERT、UPDATE、DELETE）の習得

## 学習期間・合格基準

- **学習期間**: 2-3週間
- **合格基準**: 70点以上
- **次のレベル**: Level 2: Intermediate（中級レベル）

## 学習の進め方

### ステップ1: 理論学習（推奨期間: 1週間）
1. **[`theory.md`](./theory.md)** を読んで基礎理論を学習
2. 各セクションの確認問題を解いて理解度をチェック
3. 不明な点があれば該当セクションを再読

### ステップ2: 実践練習（推奨期間: 1週間）
1. **[`practice.md`](./practice.md)** の練習問題に挑戦
2. セクション1から順番に進める
3. 分からない問題があっても一度は自分で考える
4. **[`solutions.md`](./solutions.md)** で解答と解説を確認
5. 間違えた問題は理論に戻って復習

### ステップ3: 習熟度確認（推奨期間: 数日）
1. **[`test.md`](./test.md)** で習熟度テストを実施
2. 90分の制限時間を設けて本番形式で挑戦
3. 70点以上で合格、次のレベルへ進級可能
4. 不合格の場合は弱点分野を重点的に復習

## 学習のコツ

### 効果的な学習方法
1. **理論と実践のバランス**: 理論学習後は必ず実践問題で確認
2. **段階的な学習**: 基礎から応用へ、無理をせず段階的に進める
3. **反復学習**: 間違えた問題は時間を置いて再度挑戦
4. **実環境での実習**: 可能であれば実際のデータベースで実行

### よくある躓きポイント
1. **SQL文の実行順序**: FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY
2. **NULL値の扱い**: 集約関数でのNULL値の動作を理解
3. **JOINの結合条件**: ON句とWHERE句の使い分け
4. **データ操作の安全性**: WHERE句を忘れた場合の影響範囲

### エラーが発生した場合
1. **構文エラー**: 括弧、クォート、セミコロンの確認
2. **論理エラー**: 期待した結果が得られない場合は条件を再確認
3. **パフォーマンス問題**: 大量データでの実行時は適切なインデックスを考慮
