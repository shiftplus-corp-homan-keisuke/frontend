## セクション概要

このセクションの第二部では、本格的なインタラクティブ機能を持つ初めてのプロジェクトを構築していきます。ここでは、状態管理、イベント処理、そしてフォーム操作という、Reactアプリケーション開発において最も重要な概念を学習します。

これまでに学んだReactの基礎知識を活用して、実際にユーザーが操作できるアプリケーションを作成していきます。単なる静的な表示ではなく、ユーザーの操作に応答し、データを管理し、UIを動的に更新するアプリケーションの構築方法を習得します。

### 「Far Away」アプリケーションの機能紹介

これは「Far Away」アプリケーションです。次の旅行に必要なアイテムをすべて追加できるシンプルな旅行リストです。

例えば、絶対に忘れてはいけない搭乗券が2枚必要だとしましょう。そうすると、Enterキーを押すか、ここをクリックすることができます。

すると、そのアイテムがここのリストに追加されます。また、下の方にある統計情報が更新されたことがわかります。

これだけでも、すでにインタラクティブな機能がありますが、もちろんもっと多くのことができます。

例えば、何らかの理由で充電器がもう必要なくなったとしましょう。そうすると、そこをクリックするだけで削除されます。

また、これらのアイテムを完了済み、つまり基本的にパッキング済みとしてマークすることもできます。

例えば、これとこれをすでにパッキングしたとしましょう。すると、下の方で、すでに2つパッキングしたと表示され、それは50%になります。しかし、さらに多くの機能があります。

ここにある3つの項目でソートすることもできます。入力順、説明順、またはパッキング状況順です。

そうすると、パッキング済みのアイテムが最後に表示されます。

最後に、旅行から帰ってきて次の旅行の準備をしたいときには、リスト全体を一度にクリアすることができます。

すると、本当に削除してよいかを確認され、「はい」と答えます。

すると、リストが完全に空になります。それだけです。

これは、より多くのインタラクティブ機能を学ぶのに本当に素晴らしい小さなプロジェクトだと思います。構築していくこれらの素晴らしいがシンプルな機能がすべて含まれています。

その上、この素晴らしいデザインも本当に気に入っています。少しレトロな感じで、このアプリケーションの雰囲気に本当によく合っていると思います。

## アイテムリストのレンダリング

前に言ったように、リストのレンダリングはReact開発で最も一般的なタスクの1つです。このアプリケーションも例外ではありません。

それでは、パッキングアイテムのリストをレンダリングしましょう。

まず最初に、CSSファイルに行きましょう。そこに初期アイテムの配列を貼り付けたからです。

それを取得しましょう。index.jsも閉じることができます。そして、一番上に貼り付けます。

```javascript
const initialItems = [
  { id: 1, description: "Passports", quantity: 2, packed: false },
  { id: 2, description: "Socks", quantity: 12, packed: false },
];
```

再び配列にいくつかのオブジェクトがあり、この場合、各オブジェクトはパッキングされる1つのアイテムを記述しています。

それぞれにID、説明、数量、そしてパッキング済みプロパティがあります。これは、これがパッキングされているかどうかを教えてくれます。

これに基づいて、アイテムを少し異なって表示します。

ここで、デモアプリで見てみましょう。現在はパッキングされていませんが、パッキングされている場合は、取り消し線が表示されます。

それでは、これらのアイテムを取得して、UIにリストとしてレンダリングしましょう。

名前が示すように、PackingListでそれを行います。

### mapメソッドを使用したリストレンダリング

そして、すぐにここでJavaScriptモードに入ります。Reactでリストをレンダリングする方法を覚えていますか？

単に、すでに知っているmapメソッドを配列で使用します。

```javascript
function PackingList() {
  return (
    <div className="list">
      <ul>
        {initialItems.map((item) => (
          <Item item={item} key={item.id} />
        ))}
      </ul>
    </div>
  );
}
```

initialItems、そして後で、これを動的にするときは、もちろん別の配列を使用します。しかし、今は何かをレンダリングしたいだけなので、これを動作させるためです。

mapメソッドの内部で、各要素をアイテムとしましょう。そして、各アイテムに対してレンダリングしたいのは、Itemコンポーネントです。

すぐにここに書いて、1分後にItemコンポーネントを作成します。

Item、そしてpropとして全体のアイテムを渡します。itemとしてitemです。ここを閉じましょう。

多くのアイテムがあることがわかります。コンポーネントの名前、propの名前、そしてここにオブジェクト自体があります。これは、この配列の各反復でこのコールバック関数の引数であることを覚えています。

この時点では、新しいことは何もありません。

### Itemコンポーネントの作成

ファイルを保存しますが、もちろんItemが定義されていません。それを素早く処理しましょう。

```javascript
function Item({ item }) {
  return (
    <li>
      <span>
        {item.quantity} {item.description}
      </span>
    </li>
  );
}
```

ここでpropsを受け入れる必要がありますね。このようにできることを覚えていますが、さらに良いのは、すぐにこれを分割代入して、渡したpropの名前を与えることです。それはitemです。

そして、これは何でもかまいません。O、B、G、またはXまたは何でも。しかし、ここでitemと呼ぶ方が簡単です。それがそれだからです。パッキングアイテムです。

ここで、このアイテムはLI要素であるべきです。リストアイテムです。なぜなら、それは通常、ULまたはUL要素の直接の子であるべきだからです。

そして、動作しているかどうかを確認するために、単に説明をレンダリングしましょう。item.descriptionだと思います。

はい、それです。実際にそれをコピーします。item.description、保存します。

そして、そこにあります。パスポートと靴下があります。

### スタイリングの調整

ここでスタイリングが少しおかしいです。その理由は、実際にHTMLでミスをしたからです。

ここで実際にdivを作成して、このdivがlistクラスを持つことになっています。

```javascript
function PackingList() {
  return (
    <div className="list">
      <ul>
        {initialItems.map((item) => (
          <Item item={item} key={item.id} />

```

その理由は、後でここにフィルター用の別の要素があるからです。下のこれら2つのもののためのdivがあります。

## まとめ
