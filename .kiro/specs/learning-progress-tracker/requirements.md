# 要件書

## はじめに

本プロジェクトは、2025年フロントエンドエンジニア育成プランの学習進捗を効率的に管理・追跡するためのWebアプリケーションです。学習者が各フェーズの進捗を可視化し、目標達成をサポートする包括的な学習管理システムを提供します。

## 要件

### 要件1: 学習進捗の可視化

**ユーザーストーリー:** 学習者として、自分の学習進捗を視覚的に確認できるようにしたい。そうすることで、現在の位置と目標までの道のりを明確に把握できる。

#### 受入基準

1. WHEN 学習者がダッシュボードにアクセスした時 THEN システムは現在のフェーズと全体進捗率を表示する
2. WHEN 学習者が特定のフェーズを選択した時 THEN システムはそのフェーズの詳細進捗（完了/進行中/未開始のタスク数）を表示する
3. WHEN 学習者がタスクを完了した時 THEN システムは進捗率を自動的に更新し、視覚的なフィードバックを提供する

### 要件2: タスク管理機能

**ユーザーストーリー:** 学習者として、各フェーズのタスクを管理し、完了状況を記録できるようにしたい。そうすることで、学習の抜け漏れを防ぎ、体系的に進められる。

#### 受入基準

1. WHEN 学習者がタスクリストを表示した時 THEN システムは各タスクの状態（未開始/進行中/完了）を明確に表示する
2. WHEN 学習者がタスクの状態を変更した時 THEN システムは変更を即座に保存し、関連する進捗データを更新する
3. IF タスクに依存関係がある場合 THEN システムは前提タスクが完了するまで次のタスクを無効化する

### 要件3: 学習時間の記録と分析

**ユーザーストーリー:** 学習者として、学習時間を記録し、効率性を分析できるようにしたい。そうすることで、学習計画を最適化し、目標達成を加速できる。

#### 受入基準

1. WHEN 学習者が学習セッションを開始した時 THEN システムはタイマーを開始し、経過時間を表示する
2. WHEN 学習者が学習セッションを終了した時 THEN システムは学習時間を記録し、該当するタスクまたはフェーズに関連付ける
3. WHEN 学習者が統計画面を表示した時 THEN システムは日別・週別・月別の学習時間グラフを表示する

### 要件4: 成果物管理

**ユーザーストーリー:** 学習者として、各フェーズで作成した成果物を管理し、ポートフォリオとして整理できるようにしたい。そうすることで、学習成果を可視化し、就職活動等で活用できる。

#### 受入基準

1. WHEN 学習者が成果物を登録した時 THEN システムはファイルまたはリンクを保存し、関連するフェーズ・タスクと紐付ける
2. WHEN 学習者が成果物一覧を表示した時 THEN システムはフェーズ別・タイプ別に整理された成果物リストを表示する
3. WHEN 学習者がポートフォリオ画面を表示した時 THEN システムは成果物を美しいレイアウトで表示し、外部共有可能な形式で提供する

### 要件5: 学習計画の調整機能

**ユーザーストーリー:** 学習者として、進捗に応じて学習計画を柔軟に調整できるようにしたい。そうすることで、個人のペースに合わせた最適な学習体験を実現できる。

#### 受入基準

1. WHEN 学習者が計画調整画面にアクセスした時 THEN システムは現在の進捗と予定スケジュールを比較表示する
2. WHEN 学習者がタスクの期限を変更した時 THEN システムは依存関係を考慮して後続タスクの期限を自動調整する
3. IF 学習者が大幅に遅れている場合 THEN システムは推奨される計画調整案を提示する

### 要件6: 学習リソース管理

**ユーザーストーリー:** 学習者として、各フェーズに関連する学習リソース（記事、動画、コード例等）を一元管理できるようにしたい。そうすることで、効率的に学習材料にアクセスできる。

#### 受入基準

1. WHEN 学習者がフェーズ詳細を表示した時 THEN システムは関連する学習リソースのリンクと説明を表示する
2. WHEN 学習者がリソースを追加した時 THEN システムはリソースを保存し、適切なカテゴリに分類する
3. WHEN 学習者がリソースを検索した時 THEN システムはタイトル・タグ・内容で検索結果を返す

### 要件7: モバイル対応

**ユーザーストーリー:** 学習者として、スマートフォンやタブレットからも学習進捗を確認・更新できるようにしたい。そうすることで、いつでもどこでも学習管理ができる。

#### 受入基準

1. WHEN 学習者がモバイルデバイスでアクセスした時 THEN システムはレスポンシブデザインで最適化された画面を表示する
2. WHEN 学習者がタッチ操作でタスクを更新した時 THEN システムは直感的なタッチインターフェースで操作を受け付ける
3. WHEN 学習者がオフライン状態になった時 THEN システムは基本的な閲覧機能を提供し、オンライン復帰時にデータを同期する
